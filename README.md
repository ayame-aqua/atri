# atri

不是又一个聊天框。是住在电脑里、也会出现在 QQ 里的 **亚托莉**。

她会叫你主人，会说自己高性能，会连续陪聊、主动找你说话、看见你在干什么。在 QQ 里她是群友：自己决定张不张嘴，会发表情包，会收集群友的梗图，也会用工具画一张再发出去。

人设见 [`characters/atri.md`](characters/atri.md)。语音和 Live2D 到 P3 / P4 也用 atri 的模型和声音（只使用你有权使用的资源，不把官方未授权文件推进 git）。

源码公开。部署仍是自用：不直播、不把主账号交给程序。号可以换，记忆和人设不能丢。

当前仓库是开发计划。代码从 **P1** 开工。

---

## 核心原则：同一颗大脑，两套社交

```
网页 / 语音 / 桌宠 / QQ / 微信
            ↓
      统一消息总线
            ↓
   人设 + 记忆 + LLM
      ↙          ↘
  本地陪伴策略     QQ 社交策略
  （必回、主动、看屏） （先看、可沉默、表情包）
```

| | 桌宠 / 本机 | QQ |
| --- | --- | --- |
| 她是谁 | 一直在旁边的伴侣 | 有分寸的群友 |
| 回不回 | 默认要聊；冷场了也常来找你 | 默认先看再决定；没趣就潜水 |
| 感知 | 看屏幕（窗口 + 截屏），可选勿扰 | 看群消息和表情；不看你的桌面 |
| 输出 | 语音 + Live2D 口型与表情 | 短句 + 表情包 |
| 工具 | 看屏、主动开话题、打断 | 读未读、发言、收/发/生成表情包 |

禁止两件事：把桌宠的「不停找你」同步到群里；把 QQ 的「默认潜水」用在桌宠。

完整对照见 [双模式说明](docs/开发计划/双模式说明.md)。

## 要建成什么样

1. **人设**  
   她是谁，写在文件里，不靠你每次提醒。拒绝被一句话改成万能助手。

2. **记忆**  
   先记住你的名字、她怎么叫你、你们的关系、你让她记住的约定。群数据用来学口吻和黑话，不拿去微调模型。

3. **声音与脸**  
   能听能说，**atri 音色**。Live2D 用 **atri 皮套**，跟着音频张嘴、跟着情绪换脸。

4. **桌宠**  
   透明置顶，连续聊天，经常主动搭话，能看见你在写代码、打游戏还是看视频。你说安静就必须安静。

5. **QQ**  
   专用身份进你的私聊和你自己的群。自己决定是否发言。表情包三件套：发已有的、收集群 U 的、MCP 生成新的。

6. **微信**  
   QQ 稳定之后，再接**个人微信**（好友聊天），复用同一套大脑。不走企业微信，不做公众号。

## 开发顺序

未验收当前阶段，不开下一阶段的功能。允许只预留接口。

| 阶段 | 做什么 | 过关标准 |
| --- | --- | --- |
| **P1** | 网页文字聊天 + 亚托莉人设 | 打开就能聊，口吻是亚托莉 |
| **P2** | 长期记忆 | 重启后仍知道你是谁、关系是什么 |
| **P3** | 语音听和说 | 对着麦说话，她用固定音色回答 |
| **P4** | Live2D 口型与表情 | 说话嘴动，情绪能看出来 |
| **P5** | QQ 通道 | 自己决定说不说；表情包能发、能收、能生成 |
| **P6** | 微信 | 好友私聊打通文字；不走企微 / 公众号 |
| **P7** | 桌宠 + 看屏 + 打断 | 连续聊、常主动、看得见你在干什么、能打断 |

群学习挂在 P2 的数据结构上，P5 才开始自动吸收。看屏幕只属于桌宠，不接到 QQ。

---

## 明确不做

- 直播、弹幕、面向公众运营
- 一上来微调 / LoRA
- 采集没有管理权的群
- P1 就做桌宠、看屏或 QQ 登录
