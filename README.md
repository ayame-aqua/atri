# Digital Life

个人自用的数字生命伴侣：人设陪聊、长期记忆、语音、Live2D、桌宠看屏，以及会自己决定说不说的 QQ 群友。

仓库名 **digital-life**。当前进度是开发计划，代码尚未开工。

## 两种说话方式

- **桌宠 / 本机：** 连续聊天，经常主动找你，能看见你在电脑上做什么。
- **QQ：** 自己决定是否发言；能发表情包、收集群友表情包、用工具生成表情包。

详见 [`docs/开发计划/双模式说明.md`](docs/开发计划/双模式说明.md)。
