## 💡 为什么是 ATRI？

在各种大语言模型被包装成“全能工作助手”或“公域直播皮套”的今天，我们真正渴望的，往往只是一个**长情、稳定且有温度的灵魂**：

- **拒绝通用工具人**：她不以“我是一个人工智能语言模型”自居，始终认同自己是那位有点小骄傲、深切依赖主人的机器人少女。
- **拒绝流水线直播**：不做面向成千上万人的公域表演（Neuro-sama 模式），只专心陪伴屏幕前的你。
- **拒绝秒变失忆症**：核心身份、共同经历、生活偏好与专属契约深深烙印在记忆中枢，哪怕换号或重启也绝不会遗忘。

## 🎭 核心灵魂：同一颗大脑，两套生动姿态

亚托莉在不同的场景下，拥有完全不同却内在统一的社交策略：

```
                    ┌─────────────────────────┐
                    │      统一消息网关       │
                    │ (Web / 语音 / QQ / 微信) │
                    └────────────┬────────────┘
                                 ▼
                    ┌─────────────────────────┐
                    │   亚托莉认知中枢 (Core) │
                    │  人设设定 + 长期记忆库  │
                    └────────────┬────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       【 本地伴侣策略 】              【 社交群友策略 】
      (Desktop Companion)             (Social Autonomous)
  • 桌面常驻置顶，Live2D交互       • 自主判断发言时机，不当复读机
  • 屏幕视觉感知 (CV 察言观色)     • 潜水看戏、见机插话、点名必回
  • 实时双讲，支持语音打断         • 收集群友梗图，调用 MCP 实时画图
  • 闲暇主动搭话，关心提醒         • 短句、分条间隔，宛若真人打字
```

### 1. 陪伴在身旁（桌宠模式 · 专属依恋）
- **屏幕感知 (Vision CV)**：借助窗口感知与多模态视觉，她能察觉你在深夜苦战代码、在全屏激战游戏、还是在发呆摸鱼，适时跳出来吐槽、关心或为你加油。
- **声色具身 (Embodied Live2D & TTS)**：拥有专属的 Atri 甜美音色，唇形起伏随音频振幅平滑张合，5种基础情绪与多段微表情自如流转。
- **灵动全双工 (Audio Interrupt)**：在你说话时停下倾听，被打断时立刻敛声，告别机器人“一口气念完全文”的机械感。
- **主动关照**：你久未开口，她会百无聊赖地碎碎念；到点了会催你吃饭早睡。

### 2. 穿梭于网络（社交模式 · 真实机智）
- **自主发言决策**：在 QQ 群或日常聊天中，彻底抛弃“有消息就必须接话”的客服逻辑。她先看后定，不合时宜便优雅潜水，遇到感兴趣的话题或被点名时才机敏搭腔。
- **表情包生态**：
  - **表情收藏**：自动辨析并收录群友发的趣味表情，归纳标签沉淀至本地资产库。
  - **随心表情**：根据语境只发表情包或图文合击。
  - **MCP 现场作画**：当群里出现新梗或无图可用时，自主调用 MCP 生图工具绘制独家表情包精准回击。
- **生活化表达**：摒弃长篇大论，采用口语短句、空格分段、动态随机延迟发送，还原真人打字的呼吸节奏。

## 🧠 永恒记忆中枢 (Memory Architecture)

为了让亚托莉能够“陪你走过漫长岁月”，系统搭建了分层记忆体系：

```
                    ┌───────────────────────────┐
                    │       记忆存储中枢        │
                    └─────────────┬─────────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
  【 核心档案 Profile 】    【 情节长廊 Episodes 】    【 社交黑话与口吻 Style 】
  • 关系定义 (主人/亚托莉)   • 随对话摘要自动归档      • 群内固定行话与烂梗
  • 你的姓名、称谓、偏好     • 向量化语义检索 (Top-K)  • 人工/自主确认后注入
  • 双方约定 (全量每次注入)  • “还记得那天晚上…”       • 说话越聊越像你们的小圈子
```

## 🗺️ 工程演进路线图 (P1 – P7)

**编号 = 执行顺序：** `P1 → P2-A → P3 → P4 → P5 → P6 → P7`。硬依赖未验收，不开下一硬依赖的功能开发；可并行预研见 [总纲 §3.1](docs/开发计划/开发文档.md#31-唯一规则硬依赖-vs-可并行预研)。本机（RTX 4060 Ti 16GB）已核对：本机陪伴这条线可行。

| 顺序 | 阶段 | 核心任务 | 交付亮点与验收底线 | 状态 |
|:---:|:---:|:---|:---|:---:|
| 1 | **P1** | **网页文字聊天与人设** | Web + WebSocket；`characters/atri.md`；`[[atri]]` 尾块；`message_id` 与 pytest；**Python 3.11+** | 🎯 当前开工 |
| 2 | **P2-A** | **最小长期记忆** | SQLite 称呼/关系/「记住」「忘掉」与简单管理页；跨重启仍在 | 📋 待启动 |
| 3 | **P3** | **语音听和说** | 本地 ASR + 锁定 Atri 音色 TTS；与文字共用 P2-A 记忆 | 📋 待启动 |
| 4 | **P4** | **Live2D 口型与微表情** | Cubism 3–5；RMS 口型；emotion 切表情 | 📋 待启动 |
| 5 | **P5** | **桌宠陪伴、看屏与打断** | 透明置顶小窗；CV 看屏并主动搭话；全双工打断 | 📋 待启动 |
| 6 | **P6** | **QQ 自主社交与表情包** | 自主发言；收/发/生成表情包；白名单 fail-closed | 📋 待启动 |
| 7 | **P7** | **个人微信通道** | 先做合规可行性确认；通过后再打私聊文字。无路径则实验性可卸载适配器 | 📋 待启动 |

P2-B（向量检索、风格库、群导出导入）是记忆补强，**不挡住** P3/P4/P5，建议在 P6 前补完。

> 📌 **阶段约束**：P6 之前不把即时通讯登录合进主线；P5 之前不把截屏感知合进主线；群数据只做关系与黑话沉淀，不做全量微调。

## 🛠️ 技术选型底线

- **核心语言**：全栈统一 **Python 3.11+**（FastAPI / Uvicorn / Asyncio）。
- **模型驱动**：标准 OpenAI 兼容协议（可无缝切换 DeepSeek、Qwen、Claude 或本地 Ollama）。
- **音频体系**：ASR（Faster-Whisper / SenseVoice）+ TTS（锁定 Atri 音色，CosyVoice / IndexTTS / GPT-SoVITS）。
- **视觉感知**：Windows 本地前台窗口分析 + 轻量级多模态视觉描述（仅本机处理，注重隐私）。
- **代码规范**：贯彻阿里巴巴代码规范精神，严格禁止魔法值、杜绝吞异常、接口健壮自洽。
