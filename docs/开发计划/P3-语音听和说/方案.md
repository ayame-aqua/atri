## 0. 三截怎么拆

| | P3-A 出声（硬门） | P3-B 听你（非阻塞） | P3-C 实时轮次（非阻塞） |
| --- | --- | --- | --- |
| 挡住谁 | **挡住 P4**（口型要 wav） | 不挡 P4 | 不挡 P4；不抢 P5 打断 |
| 必须有 | 打字后她用 SoVITS 说日语 | 麦克风 → 中文转写 → 同一 Agent | 点一次持续听，停顿自动送一句 |
| 为什么拆 | 先听见她 | 先证明 ASR 通路 | 免按录音，仍是一轮一轮，不是抢话 |

执行顺序里的「做完 P3 再 P4」**只指 P3-A**。

---

## 1. P3-A 要做成什么样

你打字，中文气泡出来之后（或几乎同时），自动播放她的日语。音色走本机 GPT-SoVITS `127.0.0.1:9880`。引擎没开或合成失败：文字照常，日志说明，不把整轮聊失败。

### 1.1 P3-A 要做

- `synthesize(speech_ja, emotion)` → wav
- emotion → 参考 wav（`sad` 先用 `neutral`）
- 缓存 `data/tts_cache/`（gitignore）
- WS：`assistant_text` 先发；`assistant_audio` 随后
- `GET /media/tts/{id}` 仅本机

### 1.2 P3-A 明确不做

- 麦克风 / ASR（P3-B）
- 语音打断（P5）
- Live2D 口型（P4 用本截的 wav）
- 本仓库训练 / 拷贝权重

---

## 2. P3-B 要做成什么样

麦克风中文进同一个 Gateway / Agent / MemoryStore。识别失败不瞎编、不写记忆。P3-C 之前用手动录音验证通路；现在页面入口是「对话」。

播放期间不能再开第二路。按句流式抢话留给 P5。

## 2.1 P3-C 要做成什么样

点「对话」授权麦克风后保持在听。按人声频段和底噪自适应切句，停顿约半秒送出，最长 7 秒强制切断。仍走 P3-B 的 `user_audio` / SenseVoice。她在想或在说话时先听完，不打断她。再点「结束」关掉麦。

不是全双工，也不是边听边切 token。回声靠浏览器回声消除 + 她说话时暂停切句。

## 3. 架构

```
打字 -> Agent（中文 + speech_ja）
         ├-> 中文气泡（先上）
         └-> speech/tts.py -> SoVITS 9880 -> wav -> 自动播放

（P3-B / P3-C）麦克风 ->（P3-C：VAD 切句）-> ASR（中文）-> 同一条 Agent
（P4）同一 wav 给 Live2D 口型
```

---

## 4. 选型

| 组件 | 首选 | 说明 |
| --- | --- | --- |
| TTS | GPT-SoVITS `api_v2` | P3-A。只吃 `speech_ja`。权重在原训练项目 |
| ASR | SenseVoice-Small（FunASR）；失败退 Faster-Whisper `large-v3` | P3-B。中文优先，权重本机缓存 |

```text
async def synthesize(text: str, emotion: str) -> bytes   # wav；P3-A
async def transcribe(audio_bytes, mime: str) -> str      # P3-B
```

## 5. 协议

P3-A 服务端 → 客户端（在 `assistant_text` 之外）：

```json
{ "type": "assistant_audio", "mime": "audio/wav", "url": "/media/tts/{16hex}", "duration_ms": 1234 }
```

P3-B 客户端 → 服务端：

```json
{ "type": "user_audio", "mime": "audio/webm", "data_base64": "..." }
```

服务端 → 客户端：

```json
{ "type": "user_transcript", "text": "识别出的话" }
```

**播放策略：** 译文和音频并行。气泡不必等 wav。

## 8. 验收

### 8.1 P3-A（硬门，须你本机勾选）

- [ ] 打字后中文气泡出现，并自动播放日语（不必互相等待）
- [ ] 音色稳定，连续几句是同一个人声
- [ ] SoVITS 没开时聊天仍可用，只是没声音
- [ ] 语音合成失败不丢文字
- [ ] 合成耗时有日志

### 8.2 P3-B（补强）

- [ ] 浏览器授权麦克风后能转写
- [ ] 说一句中文，气泡出现接近原意的转写
- [ ] 语音聊到的事实，刷新后纯文字再问仍在
- [ ] 空白 / 噪音：不产生胡乱记忆候选
- [ ] 播放期间不能再开第二路

### 8.3 P3-C（实时轮次）

- [ ] 点「对话」后不用再按录音，停顿约半秒会自动送一句
- [ ] 能连着两轮：你说 → 她回 → 你再说
- [ ] 她出声时你的环境声不会当成新的一句
- [ ] 「结束」后不再听

---

## 9. 交给 P4 的接口

- 每次 TTS 的 wav 可被前端拿到（`url` + `duration_ms`）
- 每次 Outbound 继续带 `emotion`
- 播放时钟：前端能对音频做 RMS

P3-B / P3-C 未完成也可以开工 P4，只要 P3-A 的 wav 在。

## 10. 借鉴（P3-B / P3-C / 以后）

- **ASR**：中文改 SenseVoice-Small（FunASR 论文 CER 约 7.8%，Whisper-large-v3 中文约 20%）。没装上再退 Faster-Whisper `large-v3`。4060 Ti 16GB 上和 SoVITS 能共存；我们 LLM 走云端，**不要**学他们「合成前杀掉 llama」。
- **失败**：空白/噪音不写 `memory_candidates`（Artemis / 本方案已写）。
- **参考 wav**：情绪目录可以后补（日常 / 害羞 / 生气），仍只吃 `speech_ja`，权重不入库。
- **轮次**：P3-C 学 AIRI / FaustBot 的 speaking 状态，只做到听和说互斥。
- **打断**：抢话停播是 P5，不要提前做。
