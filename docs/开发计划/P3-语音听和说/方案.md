## 0. 两截怎么拆

| | P3-A 出声（硬门） | P3-B 听你（非阻塞） |
| --- | --- | --- |
| 挡住谁 | **挡住 P4**（口型要 wav） | 不挡 P4/P5 的皮；建议出声通了再做 |
| 必须有 | 打字后她用 SoVITS 说日语；失败仍有中文气泡 | 麦克风 → 中文转写 → 同一 Agent |
| 为什么拆 | 先听见她，不必等 ASR 模型 | 听和说工作量不同；没麦时仍应能听她说话 |

执行顺序里的「做完 P3 再 P4」**只指 P3-A**。

---

## 1. P3-A 要做成什么样

你打字，中文气泡出来之后（或几乎同时），自动播放她的日语。音色走本机 GPT-SoVITS `127.0.0.1:9880`。引擎没开或合成失败：文字照常，日志说明，不把整轮聊失败。

### 1.1 P3-A 要做

- `synthesize(speech_ja, emotion)` → wav
- emotion → 参考 wav（`sad` 先用 `neutral`）
- 缓存 `data/tts_cache/`（gitignore）
- WS：`assistant_text` 先发；`assistant_audio` 随后
- `GET /media/tts/{id}` 仅本机

### 1.2 P3-A 明确不做

- 麦克风 / ASR（P3-B）
- 语音打断（P5）
- Live2D 口型（P4 用本截的 wav）
- 本仓库训练 / 拷贝权重

---

## 2. P3-B 要做成什么样

聊天页「按住说话 / 点击录音」。你的中文进同一个 Gateway / Agent / MemoryStore。识别失败文字回「没听清」，不瞎编。

播放期间不能再开第二路录音。按句流式、抢话留给 P5。

---

## 3. 架构

```
打字 -> Agent（中文 + speech_ja）
         ├-> 中文气泡（先上）
         └-> speech/tts.py -> SoVITS 9880 -> wav -> 自动播放

（P3-B）麦克风 -> ASR（中文）-> 同一条 Agent
（P4）同一 wav 给 Live2D 口型
```

---

## 4. 选型

| 组件 | 首选 | 说明 |
| --- | --- | --- |
| TTS | GPT-SoVITS `api_v2` | P3-A。只吃 `speech_ja`。权重在原训练项目 |
| ASR | Faster-Whisper `small` 或 SenseVoice | P3-B。中文、可离线优先 |

```text
async def synthesize(text: str, emotion: str) -> bytes   # wav；P3-A
async def transcribe(audio_bytes, mime: str) -> str      # P3-B
```

---

## 5. 协议

P3-A 服务端 → 客户端（在 `assistant_text` 之外）：

```json
{ "type": "assistant_audio", "mime": "audio/wav", "url": "/media/tts/{16hex}", "duration_ms": 1234 }
```

P3-B 客户端 → 服务端：

```json
{ "type": "user_audio", "mime": "audio/webm", "data_base64": "..." }
```

服务端 → 客户端：

```json
{ "type": "user_transcript", "text": "识别出的话" }
```

**播放策略：** 译文和音频并行。气泡不必等 wav。

## 6. 配置

```yaml
speech:

  tts_text_lang: ja
  tts_timeout_s: 60
  tts_ref_dir: data/natsume/references
  tts_cache_dir: data/tts_cache
  tts_gpt_weights: data/natsume/weights/natsume-e15.ckpt
  tts_sovits_weights: data/natsume/weights/natsume_e8_s1104.pth
  asr_model: faster-whisper-small
```

参考句路径只写本机，禁止提交。P3 **不炼丹**。

## 7. 实现顺序

**P3-A：**

1. `synthesize` HTTP + 情绪参考 wav
2. 缓存 + `/media/tts/{id}`
3. 聊天气泡后自动播
4. 失败降级为纯文字
5. 按第 8.1 节验收 → 通过后才可以开工 P4

**P3-B：**

6. `transcribe` + 录音按钮
7. 没听清 / 录音互斥
8. 按第 8.2 节验收

## 8. 验收

### 8.1 P3-A（硬门，须你本机勾选）

- [ ] 打字后中文气泡出现，并自动播放日语（不必互相等待）
- [ ] 音色稳定，连续几句是同一个人声
- [ ] SoVITS 没开时聊天仍可用，只是没声音
- [ ] 语音合成失败不丢文字
- [ ] 合成耗时有日志

### 8.2 P3-B（补强）

- [ ] 浏览器授权麦克风后能录音
- [ ] 说一句中文，气泡出现接近原意的转写
- [ ] 语音聊到的事实，刷新后纯文字再问仍在
- [ ] 空白录音 / 噪音：提示没听清，不产生胡乱记忆候选
- [ ] 播放期间不能再开第二路录音

## 9. 交给 P4 的接口

- 每次 TTS 的 wav 可被前端拿到（`url` + `duration_ms`）
- 每次 Outbound 继续带 `emotion`
- 播放时钟：前端能对音频做 RMS

P3-B 未完成也可以开工 P4，只要 P3-A 的 wav 在。
