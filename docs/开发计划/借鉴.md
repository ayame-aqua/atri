## 之后按阶段借鉴

主线不变：**P3-A 你本机听过 → P4 → P5 → P6**。记忆再补强是 **P2-C**，可穿插，**不挡口型**。

### P2-C 记忆再补强（等会先搞这个）

P2 整段已关闭。P2-C（v0.40）已按此表接线，库未换。

| 学谁 | 做什么 | 明确不做 |
| --- | --- | --- |
| **mem0** | 学 `add/search/update/forget` 和「聊完再抽事实」。实现挂在现有 SQLite + LanceDB 上 | 不装 mem0 包、不开 Qdrant |
| Artemis CCR | 每 N 轮（默认 8）抽事实 → **pending** | 未确认不进 prompt |
| Artemis `role_play` 日记 | 每天一篇短摘要；启动只注入最近几天 | 不把日记当当前对话 |
| Artemis 分数门槛 | 情节检索低于阈值不注入 | 弱相关往事不塞满上下文 |
| **荷尔蒙** | 学「隐藏状态调语气」：精力 / 别扭 / 亲近 三轴 + 衰减 | 不搬月经周期默认开；不搬九阶段恋爱条 |
| FaustBot COREMEMORY | 「她对你的稳定印象」短块，和 episodes 分开 | 不让 Agent 写 Python 模块 |
| Artemis 可读同步 | `data/` 下导出一份给人看的记忆（gitignore） | 不进 git |

召回顺序写死：**人设 < profile 全量 < 核心印象 < 相处状态 < style ≤8 < 过线的 episodes**。人设是身份，不是记忆。状态条只调语气，不改她是谁。

### P4 口型表情

| 学谁 | 做什么 | 明确不做 |
| --- | --- | --- |
| AIRI | `pixi-live2d-display`；wav RMS 张嘴；idle/眨眼 | 不抄官方 motion 名（摸胸/摸腿那套） |
| Artemis | 薄控制面：emotion 来自 `[[natsume]]`，皮和聊分开 | 不让模型每轮自己点 HTTP motion 表 |
| Artemis | 无皮时聊天和语音仍可用 | 不把 Cubism Core / 拆包推进 git |

P5 的桌宠窗再复用同一套；Artemis 的 `localhost` HTTP 桥可以那时再加，P4 先做进网页。
