## 1. 本阶段要做成什么样

她在桌面上是伴侣，不是小组件：

- 聊天是持续的，不是一问一答工单
- 你会经常被她搭话（可调、可勿扰）
- 她知道你在干什么（窗口标题 + 截屏 CV）
- 你插话她会停
- 皮套动作更跟情绪

QQ 仍然是「自己决定说不说 + 表情包」，但 **那是 P5 的事**。本阶段禁止写 QQ 登录，也禁止把桌宠的高主动设计预留成「以后同步到群」。

建议实现顺序：

**桌宠窗 → 主动搭话（先不计时屏） → CV 看屏 → 情绪动作 → 语音打断**

### 1.1 要做

- 透明置顶桌宠窗，复用 P4 Live2D
- 本地策略 `policy/local.py`：默认必回、允许连续多轮、主动出话题
- CV：前台窗口标题 + 周期性截屏（黑名单、勿扰、热键暂停）
- 看屏结果变成 system Inbound，再进 Agent（可调侃、可关心）
- 语音打断（本机）
- 更细 emotion/motion；点击互动

### 1.2 明确不做

- 直播、弹幕
- 把屏幕内容随便写入长期记忆（除非你说「记住」）
- 截屏上传到你没配置的第三方（只用你已有的多模态 LLM 接口）
- QQ 登录、群条条必回、QQ 里看你桌面

---

## 2. 连续聊天（本地策略）

与 P1「你发一条她回一条」兼容，但加上：

- 会话不因 30 秒空闲而重置
- 她可以一次说 2–3 句（多段 TTS）
- 你随时可回，上下文是一条长河
- 主动句插入同一 `web:local` / `desktop:local` 会话

`policy/local.py` 与 `policy/qq.py` 分开。本地 **没有** 默认 silent。

---

## 3. 主动经常搭话

触发（权重进 config，默认「偏勤快」）：

| 触发 | 例 | 建议默认 |
| --- | --- | --- |
| 冷场计时 | 5–15 分钟没互动 | 开 |
| 窗口切换 | 你切到游戏 / 视频 / IDE | 开（需 CV 或标题） |
| 记忆闹钟 | 「该睡觉了」 | 开 |
| 随机碎碎念 | 偶尔哼一句 | 低概率，避免机械 |

实现：后台 tick → 组装 system Inbound → Agent → TTS + 皮套。  
勿扰：热键 / 桌宠菜单；勿扰期间 tick 空转。  
同一触发冷却（例如看屏吐槽同一窗口 10 分钟内不重复）。

验收反例：开着两小时完全不说话（除非勿扰）。

## 4. CV：看到你在电脑上做什么

### 4.1 流水线

```text
前台窗口标题/进程名  →  粗分类（写代码/看视频/打游戏/浏览/未知）
        +
可选截屏（缩放后 JPEG）→ 多模态 LLM 一句话描述
        ↓
Inbound.vision + 一句 system 文本
        ↓
Agent（桌宠策略）→ 口语关心/吐槽/闭嘴（若没趣）
```

先做**标题**也能主动：「你对着 VS Code 好久了」。截屏后才能吐槽具体内容。

### 4.2 隐私

```yaml
vision:
  enabled: true
  interval_s: 30
  capture_on_focus_change: true
  use_screenshot: true
  use_camera: false
  process_blacklist: ["KeePass", "1Password", "银行"]
  title_keywords_blacklist: ["支付", "密码"]
  persist_frames: false
  max_side_px: 768
```

- 默认不把截屏当 episode 记忆
- 暂停看屏必须 ≤ 一键
- 描述失败就当没看见，不要幻觉「你在干坏事」

### 4.3 工具

本地 Agent 可有 tool `see_screen()`（主动想看时再截一次），和定时推送二选一或并存。这是本机 MCP/内部工具，**不要注册给 QQ Agent**。

## 5. 桌宠窗

- 无边框、透明、置顶、拖动、记位置
- 可选点击穿透 + 热键恢复
- Windows 优先；Electron / Tauri / pywebview 开工时锁定一个
- P1 网页保留作调试
- 气泡可极简：主要靠语音和脸

---

## 6. 情绪、动作、打断

- `motion`: nod / shake / idle / talk 等，点击头/脸可互动
- 打断：speaking 中检测到人声 → 停 TTS、停口型、取消本轮、听你的新话
- 耳机场景先验收；外放回声 P7 迭代
- 打断轮不写记忆候选
- 本阶段不向 QQ 发任何东西（通道还不存在）

---

## 7. 本阶段不碰 QQ

P5 才做：silent、表情包、MCP、状态机。P7 不要提前写 `policy/qq.py` 的登录侧逻辑。本地 Agent **不要**把 `see_screen` 设计成将来能注册给 QQ。

---

## 8. 实现顺序

1. 桌宠窗 + 原有聊天语音
2. 冷场主动搭话（无 CV）
3. 窗口标题 → 主动
4. 截屏多模态 → 主动 / `see_screen`
5. 勿扰、黑名单、冷却
6. motion + 点击
7. 语音打断
8. 按第 9 节验收（不要夹带 QQ）

---

## 9. 验收

- [ ] 桌宠可拖、置顶、透明
- [ ] 持续对话不无故清空上下文
- [ ] 非勿扰下，一段时间不理会她，她会主动搭话
- [ ] 切到明显不同的应用，她有可能提到你在干什么（标题或截屏）
- [ ] 黑名单窗口不截屏；热键能暂停 CV
- [ ] 屏幕细节默认不出现在 `/memory` 的 profile 里
- [ ] 能打断她说话，口型停
- [ ] 无 QQ / 微信登录代码
- [ ] 本地 Agent 的看屏工具不能以「给 QQ 用」的方式注册
