## 1. 本阶段要做成什么样

浏览器打开本地页面，输入文字，她按人设回复。刷新页面后角色还是同一个人（人设来自文件，不靠你当场提醒）。连续多轮对话不丢短期上下文。

**本阶段结束时，她已经「是谁」；还不必记住你是谁（那是 P2）。**

产品原则（本阶段只落实一半）：本地通道 **默认必回、当陪伴**；QQ 的「自己决定说不说 / 表情包」到 P5 再做。详见 [双模式说明.md](./双模式说明.md)。`OutboundMessage.silent` 字段 P1 就要有（Web 恒为 false），免得 P5 再改协议。`vision` 字段可留空。

### 1.1 要做

- FastAPI + WebSocket 后端
- 单页聊天前端
- `characters/atri.md` 亚托莉人设
- OpenAI 兼容 LLM 调用
- 统一内部消息 `InboundMessage` / `OutboundMessage`
- `Channel` 抽象；Web 作为第一个通道
- 短期会话上下文（进程内即可，可顺手落盘，不要求跨进程长期记忆）
- 解析隐藏字段 `emotion`（给 P4 用，本阶段前端可先忽略或只显示小标签）
- Memory 空实现（只提供接口，返回空）
- `channels/qq.py`、`channels/wechat.py` 只放空壳，不写登录

### 1.2 明确不做

- 长期记忆、记忆管理页
- 麦克风、TTS、Live2D、桌宠
- 任何即时通讯登录、收发、协议
- 微调模型、向量库
- 复杂账号体系、用户注册

## 4. 数据与协议

### 4.1 内部消息（本阶段定稿，后续阶段只填字段）

见总纲 4.1。P1 实际用到的最小集：

```text
InboundMessage
  channel = "web"
  chatType = "dm"
  chatId = "web:local"
  senderId = "user"
  senderName = "你"          # P2 再被记忆覆盖
  text, createdAt

OutboundMessage
  chatId = "web:local"
  texts = ["回复"]
  emotion = "neutral" | "happy" | "sad" | "angry" | "shy"
  silent = false
```

### 4.2 WebSocket 帧（浏览器 ↔ 后端）

客户端 → 服务端：

```json
{ "type": "user_text", "text": "你好" }
```

服务端 → 客户端：

```json
{ "type": "assistant_text", "texts": ["今晚风有点大。"], "emotion": "shy" }
{ "type": "error", "message": "LLM 调用失败" }
{ "type": "status", "state": "thinking" | "idle" }
```

一条用户消息对应一次 `thinking`，再一条或多条 `assistant_text`（P1 可以只发一条）。

### 4.3 HTTP

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/` | 聊天页 |
| GET | `/api/health` | 健康检查 |
| GET | `/api/character` | 返回人设名字等元数据（不含完整系统提示） |
| WS | `/ws/chat` | 聊天 |

管理类接口一律绑 `127.0.0.1`。

## 5. 人设文件规格

路径：`characters/atri.md`（亚托莉，不要改成空白通用助手）

实际内容以仓库里的 `characters/atri.md` 为准，不要另写一套通用助手人设。结构示意见该文件（front matter + 身份 / 说话方式 / 禁区 / 输出格式）。

`persona.py` 负责读文件、把正文拼进 system。换这个 md 再开新会话，性格必须可感知地变。

## 6. Agent 拼装（P1 子集）

P1 的 system 只含：

1. 人设正文
2. 通道规则：现在是网页私聊，可以正常回，不要 `silent`
3. 输出格式（emotion 行）

不含：长期记忆、黑话表、群规则。

`agent.py` 流程：

1. 载入人设
2. 取 `SessionStore` 最近 20 轮
3. 调 LLM（非流式即可）
4. 拆出可见文本与 `[[emotion:...]]`
5. 把这一轮写入 SessionStore
6. 返回 `OutboundMessage`

LLM 失败：前端提示错误，不写坏会话。

## 7. Channel 抽象

`channels/base.py`：

```text
class Channel(Protocol):
    name: str  # "web" | "voice" | "qq" | "wechat"
    async def start(self, gateway) -> None
    async def send(self, message: OutboundMessage) -> None
```

- `WebChannel`：把 WS 收到的文本变成 Inbound，把 Outbound 推回同一连接
- `qq.py` / `wechat.py`：空类，`start` 为空操作或明确 `NotImplemented`，**禁止**出现登录逻辑
- `gateway.py`：`handle(inbound) -> agent.run -> channel.send`

P1 就把 Gateway 写成「按 channel 分发」，这样 P3/P5 只加通道，不改 Agent。

class MemoryStore:
