## 0. 现在不要做

P1–P7 是 demo / 产品主线：网页、记忆、语音、皮套、桌宠、QQ、微信。**本仓库现在不接训练框架、不炼丹、不把群记录整锅拿去训。** SoVITS 音色仍走仓库外已炼好的权重，P8 不管声音。原作脚本、拆包、台词表**永不进 git**。

---

## 1. 要做成什么样

本地（或你自己的机器）跑开源底模，挂上四季夏目 LoRA，Agent 只换 `LLM_BASE_URL` / 模型名，人设文件、记忆、通道都不推翻。

### 1.1 语料（主次不能反）

| 优先级 | 来源 | 说明 |
| --- | --- | --- |
| **主料** | 你买过的《星光咖啡馆与死神之蝶》里，**四季夏目本人说出的台词** | 学口吻和处事，不是学整条路线。只留本机，不入库、不公开 |
| 不要当正例 | 网页/QQ 陪聊记录 | 那些轮次大量改过、本身就有 OOC，拿去训等于把客服腔焊进去 |
| 可极少混 | 你确认**完全**在人设里的私聊 | 只为了让她习惯「发消息给现在的你」，避免 LoRA 只会走 gal 场景、吧台点单 |

抽取时只要她的对白，去掉旁白、选项、别人的话、大段剧情独白。运行时仍然不剧透、不复述游戏原句（人设禁区还在）。

### 1.2 训练与验收

- 离线批次微调（LoRA / QLoRA），训完再部署。不能在对话里改权重。
- 验收：关掉云端 Key 仍能按人设聊；口吻像原作夏目，而不是把店里剧本演一遍。

---

## 1.3 明确不做

- 微调 DeepSeek / 任何托管 API 上的公共模型
- 边聊边更新梯度
- 用未筛选的陪聊、OOC、群原文当正例
- 把原作脚本、拆包、台词推进公开仓库
- 在本仓库训练 GPT-SoVITS
- 把 P8 提前合进 P1 的 `src/`（预研只允许读文档、试本机 Ollama，禁止合入训练循环）

- Artemis 证明 8GB 也能挤本机大模型，那是他们全本地的补丁。我们 16GB 留给 SoVITS / 以后 ASR / 看屏 VLM；**P5 对齐前不换云端对话模型**。

- FaustBot 的自我进化是模型写 Python。我们继续用 living notes 纠偏；P8 只训原作夏目台词 LoRA。
- Artemis 后宫底模、网页 OOC、群原文不当正例。
