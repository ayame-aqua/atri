GPT-SoVITS **权重已在别的项目炼好**。本仓库不训练、不拷贝 ckpt/pth，只打本机推理 API。

P3-A 调本机 `api_v2`（默认 `127.0.0.1:9880`）。引擎没开或合成失败时文字聊天仍可用。

在 GPT-SoVITS 工程目录用夏目权重启动：

```text
python api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer_natsume.yaml
```

`502` / `400` 是引擎推理失败（权重没挂上、参考 wav 读不到等），看 SoVITS 控制台和我们日志里的 `tts status=... body=...`。
