## 做什么

在现有 SQLite + LanceDB 上补齐 `add/search/update/forget`。每 8 轮抽事实进 pending；日记和核心印象分开注入；情节低于分数且无关键词重叠不进 prompt。相处状态三轴（精力 / 别扭 / 亲近）带衰减，只调语气。月经周期锁死关闭。

## 为什么

学 mem0 的增删改查和荷尔蒙的隐藏状态，不换库、不上恋爱进度条。

## 改了什么

- `memory/schema.sql`：`diaries` / `impressions` / `mood_state`
- `src/memory/store.py`、`mood.py`、`extract.py`、`vectors.py`：检索门槛 + 关键词兜底
- `src/core/agent.py`：注入顺序为人设 → profile → 印象 → 状态 → style → 日记 → 情节
- `src/main.py`：`GET /api/memory/mood`、`POST /api/memory/export`、确认印象、摘要同时写当天日记
- `config.yaml`：`extract_every_n` / `episode_min_score` / `mood`
- `tests/test_memory_p2c.py` 及 HTTP / Agent 回归
- P2 方案、总纲
