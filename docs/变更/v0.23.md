## 做什么

真聊后发现「模型写日语再译中文」会把气泡译成电报和机翻腔。改为：模型直接写中文气泡；另开短请求译成日语写入 `speech_ja` 给以后 SoVITS。展示前把句中句号收成逗号。

## 为什么

用户主要看中文。输入本来就是中文、没有转日语。日→中翻译层再好也救不了「先写成日语体言止」。句号堆叠同样是展示问题，用确定性收口比只靠 prompt 稳。

## 改了什么

- `src/core/translate.py`：`chinese_to_japanese`；失败则 `speech_ja` 留空，不影响气泡
- `src/core/agent.py`：可见正文为中文；历史只注入中文
- `src/core/text_style.py`：句中「。」→逗号，去掉句末句号
- `src/core/protocol.py`、总纲 §4.3、P1 流程与验收：对齐中文直出
- `tests/test_agent.py`、`tests/test_text_style.py`
