## 做什么

把 `characters/natsume.md` 从短提纲扩成可指导模型的角色说明书：人设内核、关系阶段、情境推拉逻辑、禁区与 `[[natsume]]` 约定；不堆原作剧透、不写方言/口音细则。

## 为什么

P1 已能真聊时，v0.20 人设过短，模型易滑成通用助手。参考社区 Gal 助手「厚 setting + 行为树」思路，分两轮收敛内容，避免只加剧情复述。

## 改了什么（两轮，同一文件）

**第一轮（结构加厚）**

- 按「背景 / 性格 / 语言习惯」编号扩写生活细节与禁区
- 补充多组情境对照，约束短句与反助手腔

**第二轮（收敛为「人设 + 对话方式」）**

- 重写为：心理防御机制、生活矛盾、与对方三阶段关系
- 增加五大情境的多轮反应逻辑树（夸奖、诉苦、当工具人、越界指令、日常沉默）
- 明确禁止括号旁白、条列总结、中文正文；保留输出协议与 emotion 语义
