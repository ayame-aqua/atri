## 做什么

实时对话的音量和转写落到 `data/speech_debug.log`（不进 git），方便对照「你说了什么 / 它听成了什么」。

ASR 从 Faster-Whisper `small`（CPU int8，中文常听成「谢谢观看」）换成 SenseVoice-Small。没装 FunASR / 加载失败时再退 Faster-Whisper `large-v3`。

## 为什么

Whisper `small` 中文弱。SenseVoice-Small 是 FunASR 的开源中英粤日韩模型，公开基准中文 CER 大约 7.8%，同表 Whisper-large-v3 大约 20%。

## 改了什么

- `src/speech/asr.py`：SenseVoice + 回退；webm 先解成 16 kHz wav
- `src/speech/debug_log.py`：本机语音调试日志
- `config.yaml`：`asr_model: sensevoice-small`
- `pyproject.toml`：`speech` extra 加 `funasr`
- P3 方案、本地资源、总纲版本
