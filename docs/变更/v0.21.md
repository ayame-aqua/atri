## 做什么

接通 P1 主路径：FastAPI + WebSocket 网页聊天、Gateway 去重、`Agent` 调 OpenAI 兼容 LLM、解析 `[[natsume]]`、日语台词译成中文气泡；21 项 pytest 全绿。

## 为什么

v0.19/v0.20 只有骨架与文档收口，浏览器还不能真聊。本版把总纲 §4.3「日语正文 + 中文气泡」落到可运行代码。

## 改了什么

- `src/main.py`：应用生命周期、`/api/health`、`/api/character`、静态页、`/ws/chat`
- `src/core/agent.py`、`llm.py`、`translate.py`、`persona.py`、`errors.py`
- `src/gateway.py`：`handle()` 串联去重 → Agent → 回推
- `src/channels/web.py`：WebSocket 帧与 Outbound 推送
- `web/`：单页聊天 UI（中文气泡）
- `tests/test_agent.py`、`test_gateway_handle.py`、`test_http.py`、`test_web_frames.py`
- `.env.example`、`config.yaml`、`pyproject.toml`：LLM 环境变量与依赖微调

## 未做

- 未提交 `.env`；无 Key 时 `llm_ready` 为 false，需本地填 `LLM_API_KEY` 后验收真聊
- P2-A SQLite、语音、Live2D、QQ/微信登录仍不做
- `characters/natsume.md` 仍沿用 v0.20 短版（人设加厚见 v0.22）
