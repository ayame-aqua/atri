## 做什么

把空的 `MemoryStore` 换成 SQLite。能「记住 / 忘掉 / 我叫 X 你叫我 Y」，重启还在。聊天页有记忆管理。低风险 `prefers.*` 候选才自动写；坏尾块不写盘。

## 为什么

P1 文字 demo 够自用。语音和桌宠之前必须跨重启记得你，否则出声仍是失忆。
