## 做什么

聊天页加录音。浏览器把 webm 发给后端，Faster-Whisper `small` 转成中文，再走和打字同一条 Gateway / Agent / 记忆。她在说话时不能再开第二路录音。空白或噪音只提示「没听清」，不进记忆。

## 为什么

P3-A 已经能出声。听你不挡口型，但要和文字共用记忆，否则用嘴说的约定刷新就丢。

## 改了什么

- `src/speech/asr.py`：懒加载 Faster-Whisper；短音频 / 高 no_speech / 不足两个有效字当没听清
- `src/channels/voice.py`：`user_audio` → 转写 → `channel=voice` 的 Inbound
- `src/main.py`、`web/app.js`：录音按钮、`user_transcript`、播放期间禁用录音
- `pyproject.toml`：可选依赖 `.[speech]`
- P3 方案、总纲、README、本地资源
