## 做什么

按 SillyTavern 一类项目的分层来压 OOC：人设只管性格；硬事实常驻；说到同桌 / 班主任 / 主人才插入对应条目；用户消息后再贴一条短提醒（Post-History）。

## 为什么

只加人设禁止项解决不了「顺着编高中同桌」。社区做法是世界书按需注入 + 靠近生成点的指令，而不是把问答写进人设。

## 改了什么

- `src/core/lore.py`：常驻大学 / 咖啡馆；关键词触发高中班级、主人、AI
- `src/core/agent.py`：system 含常驻事实；用户句后追加 `trailing_system`
- `tests/test_lore.py`：无关闲聊不插入班级条目；同桌句会插入
